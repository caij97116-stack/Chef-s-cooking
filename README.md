# 大厨烹饪处 · SillyTavern 扩展

一个酒馆里的**写作工作台**：核心是「文风蒸馏」——把语料熬成一段可以直接用的**文风块**，填进预设的一条 prompt 或世界书的一条 entry。在它周围还有六个常用模块：开场白工坊、楼层改写、角色说话腔、卡片润色、世界书补条目、体检。

## 安装

在 SillyTavern 里打开 **扩展 → 安装扩展**，粘贴本仓库地址：

```
https://github.com/caij97116-stack/Chef-s-cooking
```

安装后确认扩展已启用。入口在输入框右侧的 **魔法棒** 菜单里，点「大厨烹饪处」打开面板。

## 界面总览

- 面板顶部是**模块标签页**：🔥 文风蒸馏 / 🎬 开场白 / ✏️ 楼层改写 / 🗣 说话腔 / ✨ 卡片润色 / 📚 世界书 / 🩺 体检。每个模块是独立的流程，共用同一套模型调用、缓存和存档底子。有问题的体检会在标签上红标。
- 文风蒸馏里是**向导式流程**：顶部步骤条 ① 喂料 → ② 读解 → ③ 确认① → ④ 确认② → ⑤ 成块 → ⑥ 拿走，走到哪亮到哪；区块按进度渐进显示，没轮到的先藏起来。
- 标题旁显示**本会话**调用次数（设置抽屉里是累计数），以及命中缓存省下的次数。
- 配色跟随酒馆主题；面板里的按钮用自己的底色和字色，压过主题把 `.menu_button` 刷成白字看不清的情况。主操作是深蓝实心底 + 白字。
- 手机端自动单列布局。点右上角 × 或点背景、按 Esc 收起面板。

## 模块一 · 文风蒸馏

### 用法

1. **喂料**：选来源和体裁，起个名字。来源分三档，理解深度依次加深：
   - **别人贴的素材**（参考文字）：当成现成范文直接分析。
   - **自己写的正文**：也是分析文字本身，但会多提醒模型「作者本人未必清楚自己的习惯」，往深里挖。
   - **自己写的文风指令**：贴的是规则/要求而不是范文，模型会先读懂指令再推演；这一档下面会多出一个「补充说明 / 可参考的文案」框。
   懒得贴就点「取角色卡」或「取聊天」自动填。
2. **开始读解**：分析句法 / 对象 / 态度 / 修辞，结果一行一条摆给你看；哪层不满意点它的「重读」只重读那一层。
3. **确认① · 信念与禁忌**：勾选 / 改信念，看禁忌清单（建议至少 6 条，最锋利的由你补），点「确认这一步」。一次读完时后三遍已经带上；没开一次读完时，第一次点会先补读后三遍，看完禁忌再点一次确认。
4. **确认② · 拿不准的拍板**：模型不敢定的地方你填一句；没有拿不准也可以直接点「确认并润色成块」。
5. **成块**：先本地按模板拼一份草稿，再让模型润色一次成可执行文风块。润色失败会留下草稿，可手改。
6. **拿走**：复制、下载 JSON、导入 JSON、存进**文风存档**（最多 50 份），或导出 / 写入世界书。

状态自动保存，刷新后还在。

### 省 API

- **一次读完（默认开）**：全部读解合并成一次调用，少花一半调用。想分步细读就取消勾选。
- **输入缓存**：读解、润色都按输入算指纹，输入没变时点按钮直接复用上次结果，不再打 API。每阶段保留最近 2 次。想强制重跑，按住 Shift 点按钮。
- **只重读一层**、**样本代替全文**、**防重复扣费**：细节同旧版。

## 模块二 · 开场白工坊

给当前角色写开场白：**贴料 → 生成 → 挑 → 拿走**。

- **选题源**：点「取角色卡」自动填描述 / 性格 / 场景 / 示例对白；「刷新世界书列表」列出所有世界书勾选框（默认勾上角色已挂载的那本，可以自由加减），「角色卡 + 勾选的世界书」按勾选的书自动带上里面没被关掉的条目。都可以手动增删。
- **选文风**：用当前面板里的文风块、从文风存档里挑一套，或「不用文风，只写开场白」。
- **选人设**：用当前 {{user}} 人设，或自己写一段简介；不管选哪种，生成的正文都不会直接点出 {{user}} 的具体人设名字，统一用「你」/ {{user}} 宏。
- **选场景**：初次见面 / 已经熟识 / 冲突之中 / 自定义（一句话描述）；可选生成 2~3 条；字数分简短 / 适中 / 详细三档。
- **挑**：候选并排预览，每条有「重写这一条」「就用这条」，以及直接「写第一条」「加备选」——不用先选中再去下面点。
- **拿走**：复制；**写为第一条开场白**（写进 first_mes，会覆盖）；**加为备选开场白**（追加到 alternate_greetings，切换角色时可轮换）——写回前弹窗确认。也有独立的开场白存档（最多 20 条）。

## 模块三 · 楼层改写

在聊天里挑一条最近的 AI 发言（点列表选中），用当前文风块重写这一楼。改写结果可手改，点「写回这一楼」确认后覆盖原楼并保存聊天。文风块为空时会提示先去蒸馏或载入存档。

## 模块四 · 角色说话腔

单独蒸某个角色**开口的腔**（文风管叙述者的笔，说话腔管角色开口的调）：

- 喂对白：取角色卡示例对白，或取聊天里的角色发言，也可手动贴。
- 蒸出一条「说话方式」条目：称呼与自称、语气词与口头禅、句长节奏、标点、情绪外露程度、绝不出现的话。
- 可手改，复制贴进角色卡 / 世界书，或直接**写入世界书**（触发关键词为「角色名 · 说话方式」）。

## 模块五 · 卡片润色

用文风块重写角色卡的**描述 / 性格 / 场景**，让卡片文本本身就带上味道：

- 点「取角色卡」把三个字段取下来，可手动增删；
- 「用当前文风润色」一次改写所有非空字段，人物设定、事实、数值不动，只改写法；
- 检查后「写回角色卡」，覆盖前弹窗确认。

## 模块六 · 世界书补条目

给不知道世界书(lorebook)该怎么写的人用，有两种取材方式：

- **根据角色分析**：点「取角色卡」，从角色素材里挑值得展开的概念/设定，生成几条条目。
- **联网搜索真实资料**：填一个词（概念/地点/年代），走的是维基百科的公开接口——不是通用搜索引擎，只能查到维基百科收录的内容，查不到冷门或虚构设定；查到的资料可以自己改删，再据此生成条目。
- 两种方式都可以填一句「想要的方向」，生成 2/3/5 条，每条给触发关键词和正文，逐条勾选、可编辑，「把勾选的写进世界书」时选已有的书或填新书名——条目是关键词触发（selective），不是常驻注入，不会一直占提示词。

## 模块七 · 体检

看**上一轮请求**里，世界书和预设有没有真正带上。勾选只代表打算用；进没进请求才算用上。不声称模型在回复里有没有照着写。

- 默认**边玩边检**：每次真正发一轮就刷。也可以点「检这一轮」手动看。
- **世界书**：按扫描结果列出触发的条目和原因（常驻 / 关键词 / 向量）。预算满了、正文空、一条都没激活，会红标。
- **预设**：对照 Prompt Manager 的勾选 vs 上一轮拼好的提示词。勾了但请求里找不到这段、内容是空的，会红标。聊天记录这类占位项只标「酒馆现场填」。
- 文本补全读不到 Prompt Manager 时，只做世界书对照。

## 生成方式

- **当前酒馆连接的模型**（默认）：用你在 SillyTavern 里已连好的模型，不用另配 Key。
- **自定义站子 / 模型**：填 Base URL 和 API Key，点「拉取模型」拉列表。API Key 默认只在本次会话有效，勾「记住 Key」可留在本机。流式输出只对自定义站子生效。
- 「停」按钮只在自定义站子模式下能真正中断请求；「当前酒馆模型」模式下它是置灰的（这版酒馆接口不支持中断），点了也会把这轮结果丢弃。

## 填进世界书

文风块和说话腔条目都能进世界书：

- **导出世界书**：下载合法的酒馆 lorebook JSON，在「世界信息」面板导入。
- **写入世界书**：下拉选已有世界书或填新名字，弹窗确认后追加一条常驻 entry。没有写入接口的版本会提示改用导出。

## 文件

- `manifest.json` 扩展清单
- `index.js` 入口：模块标签页、七个模块的 UI 与流程、状态、调用模型、缓存、体检事件挂钩
- `prompts.js` 读解 / 润色成块 / 改写 / 开场白 / 说话腔 / 卡片润色 / 世界书的提示词
- `style.css` 样式（跟随酒馆主题变量；面板按钮自管字色底色）

## 方法来源

参考两个公开蒸馏 skill 的纪律：两道人工确认、黑名单至少 6 条且由用户补最锋利的一条、借结构不借句子。成块是本地拼草稿后再润色一次。

## 边界

- 只蒸馏自己的或已获授权的语料。
- 语料只发给你在 SillyTavern 里连接的那个 API。
- 玩法（AI 要不要替 `{{user}}` 发言）单独一栏，默认空，不并入文风。
