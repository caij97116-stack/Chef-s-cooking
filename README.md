# 大厨烹饪处 · SillyTavern 扩展

采料、慢炖、出锅：把语料熬成一段可以直接用的**文风块**。文风块能填进预设的一条 prompt，也能填进世界书的一条 entry——填哪里由你决定，本扩展不生成容器，也不碰 keys、position、order。

## 生成方式

- **当前酒馆连接的模型**（默认）：用你在 SillyTavern 里已经连好的模型，不用另配 Key。
- **自定义站子 / 模型**：切到这一档，填 Base URL 和 API Key，点「拉取模型」把模型列表拉下来（也可以手填模型名）。适合用中转站的人。
  - API Key 默认只在本次会话有效；想让它留在本机、下次还开着，勾上「记住 Key」。不勾，刷新后就需要重填。
  - 勾上「流式输出（只对自定义站子生效）」，拼文风块、回炉、改写这几步会边收边显示，不用干等；站子不支持流式时会自动回退成一次返回。

## 安装

在 SillyTavern 里打开 **扩展 → 安装扩展**，粘贴本仓库地址：

```
https://github.com/caij97116-stack/Chef-s-cooking
```

安装后确认扩展已启用，在 **扩展设置** 面板里能看到「大厨烹饪处」的开关与入口。

## 界面

- 工具本体是页面右下角的圆形悬浮球，点一下展开磨砂玻璃面板；点右上角 × 收起。
- 悬浮球**可拖动**，面板标题栏也可拖动，位置自动记住，刷新后还在。
- 面板顶部有「停」按钮，可中止本次生成；标题旁显示本会话已调用模型的次数，以及命中缓存省下的次数。
- 设置面板里只留一个「显示悬浮球」开关，不开就没入口、界面保持干净。

## 看不到悬浮球？

- 悬浮球不依赖酒馆的扩展设置容器，装好并启用后就应该出现在右下角（在输入栏上方一点）。
- 若刚更新过代码，请在酒馆的「扩展」里对本扩展点一次「更新」（或重新安装），再按 Ctrl+F5 硬刷新页面，避免浏览器缓存旧脚本。
- 仍然没有的话，打开浏览器控制台看有没有 `[大厨烹饪处]` 开头的日志：出现「悬浮球已挂载」说明已挂上，否则请把报错发出来。

## 省 API

- **省流模式（默认开）**：面板里「省流」勾上时，七遍读合并成一次调用返回，比分开读少花一半调用；想分步细读就取消勾选。
- **合并调用**：草稿与拿不准清单并入读解一次返回，切「来源」不会因此重跑整段分析。
- **输入缓存**：句法/对象/态度/修辞、后三遍、成块、改写都按输入算指纹，输入没变时点按钮直接复用上次结果，不再打 API。每阶段保留最近 5 次结果，来回改再改回来也能命中。想强制重跑，按住 Shift 点按钮，或用 web 版的「强制重跑」。
- **只重蒸一层**：前三遍读的每一层旁边有「重蒸」，只重读那一层，比整段重读省。
- **样本代替全文**：读解时顺手剪出 2-3 段代表原句，压成块时用样本，不再把整篇语料再发一遍。
- **防重复扣费**：一次调用没结束时，重复点按钮会被忽略，不会并发重复发请求。
- **计数可见**：面板标题实时显示调用次数、省下的次数与 token（自定义站子返回 usage 时）。

## 用法

1. **喂料**：选来源（我的文字 / 参考文字）和体裁，贴同一体裁的语料，起个名字。懒得贴就点「取角色卡」（拿当前角色的描述 / 性格 / 场景 / 示例对白）或「取聊天」（拿当前聊天里角色的发言）自动填进去，可再增删。
2. **开始六遍读**：前三遍（句法 / 对象 / 态度 / 修辞）出来，并给 2-3 个**信念候选**。哪一层不满意就点它的「重蒸」。选「参考文字」时还会多出一张**拿不准**清单，模型不敢定的地方由你逐条定夺，这些决定会带进成块。
3. **卡点·信念**：逐条选 / 驳 / 修，确认后读后三遍（历史定位 / 黑名单 / 核心信念）。省流模式下这一步通常直接复用，不再打 API。
4. **卡点·反例**：AI 起草黑名单，你补那条最锋利的反例（至少 6 条）。
5. **压成文风块**：生成可直接贴的文字。
6. **测试门**：拿一段默认 AI 腔让它用文风改写，你判像 / 不像。点「不像」会自动回炉重修文风块，再测，直到你满意；也可自己手改文风块或重蒸漂的那层。
7. **拿走**：复制文风块，下载 JSON 存档，导入别处存下的 JSON / 蒸馏池，存成一份本地「文风存档」（最多 50 份，可载入 / 覆盖 / 删除），或导出 / 写入世界书。

状态会自动保存到扩展设置，刷新后还在。

## 多套文风存档

- 熬好一套后，在「拿走」区给它起个名，点「存为存档」，整套结果（文风块、六遍读、黑名单、草稿、拿不准、玩法备注）都会存下来。
- 下拉选一份，可「载入」（把当时那套原样铺回面板）、「覆盖」（用当前面板内容更新它）、「删除」（会再问一次）。
- 最多 50 份；存档只存在你自己的酒馆设置里，不联网。
- 「导入 JSON」认两种文件：本工具「下载 JSON」的完整存档，以及「下载蒸馏池」的六遍读结果。导入即铺回面板，想留存再手动「存为存档」。

## 填进世界书

文风块要当世界书用时，有两种方式：

- **导出世界书**：下载一份合法的酒馆 lorebook JSON（一条常驻 entry，关键词是文风名），在「世界信息」面板用「导入」加载。
- **写入世界书**：下拉选一本已有的世界书，或填个新名字新建，点「写入世界书」会弹窗确认，然后追加一条常驻 entry 并刷新世界信息面板。写入前会先告诉你要写进哪本、触发关键词是什么。若你的酒馆版本没有世界书写入接口，会提示改用「导出世界书」。

## 文风块长这样

```
# 冷硬短句 · 身体叙事
> 写作时不许解释情绪，只准把情绪写成身体正在做的事。

信念：人不会说出自己真正在感受的东西；写出来的是动作，读者自己拼情绪。
句法纪律：短句为主，一句一个动作；形容词能删就删；几乎不用"因为/所以"。
修辞习惯：情绪落在手、呼吸、光、物件的动作里；对白短，常被动作打断。
跟邻居的界：不靠留白和省略号装冷，靠动作密度。
反例（绝不写）：
- 不禁、宛如、映入眼帘、一抹、低语、值得注意的是
- "不是A，而是B"式排比
样本：
（原文剪段）
```

## 文件

- `manifest.json` 扩展清单
- `index.js` 入口：悬浮窗 UI、状态、调用当前模型、缓存
- `prompts.js` 六遍读 / 按层重蒸 / 成块 / 改写的提示词
- `style.css` 样式
- `web/` 纯前端静态版：同样是悬浮球 + 可拖动悬浮面板，进度存 localStorage，可挂 GitHub Pages

## 方法来源

参考两个公开蒸馏 skill 的纪律：两道人工卡点、黑名单至少 6 条且由用户补最锋利的一条、借结构不借句子、用默认 AI 腔做测试门。

## 边界

- 只蒸馏自己的或已获授权的语料。
- 语料只发给你在 SillyTavern 里连接的那个 API。
- 玩法（AI 要不要替 `{{user}}` 发言）单独一栏，默认空，不并入文风。
