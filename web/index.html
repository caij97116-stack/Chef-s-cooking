喂料

同一体裁的语料，越多越稳。默认不出域。

六遍读

句法 / 对象 / 态度 / 历史定位 / 黑名单 / 信念压缩。第一次读出的声音通常是错的。

卡点·信念

选 / 驳 / 修。没有你确认，不进下一步。

卡点·反例

黑名单是最重要的部分，至少 6 条。最锋利的一条由你补。
你补的那条（她打死也不会写的）

成块

只留能贴的那段。不出现“技法 / 养成 / 层次 / DNA”这类词。

测试门

喂一段默认 AI 腔，用文风改写。你判像不像，不像只重蒸漂的那层。

拿走

文风块填哪里是你的自由，工具不管容器。
