# 大厨烹饪处（静态版）

纯前端静态页面。语料进，文风块出。文风块是一段纯文字，可以被填进 SillyTavern 预设的一条 prompt，或世界书的一条 entry；本工具不生成容器，也不碰 keys / position / order。

## 用法

1. 打开页面，点「API 设置」，填入 OpenAI 兼容接口的 Base URL、Key、模型、温度。Key 默认只在本次会话有效；勾选「记住 Key」才写入当前浏览器的 localStorage，下次自动填回。
2. 点右下角悬浮球打开面板；悬浮球和面板都能拖动，位置会记住。
3. 「喂料」：选来源与体裁，贴同一体裁的语料，起个名字。懒得贴就点「导入角色卡 JSON」，读酒馆导出的角色卡文件，自动提取描述 / 性格 / 场景 / 示例对白填进语料框，可再增删。
4. 「开始六遍读」。输入没变时会直接复用上次结果；想强制重跑点「强制重跑」。选「参考文字」时会多出一张「拿不准」清单，模型不敢定的地方由你逐条定夺，带进成块。
5. 「卡点·信念」：选 / 驳 / 修 AI 给的信念候选，确认后读后三遍。省流模式下这一步通常直接复用，不再请求。
6. 「卡点·反例」：AI 列黑名单，你补那条最锋利的反例。
7. 「压成文风块」。
8. 「测试门」：拿一段默认 AI 腔让它用文风改写，你判像不像。点「不像」会自动回炉重修文风块，再测，直到你满意；也可自己手改或重蒸漂的那层。
9. 「拿走」：复制文风块，下载 JSON / 蒸馏池，导入别处存下的 JSON / 蒸馏池，存成一份本地「文风存档」（最多 50 份，可载入 / 覆盖 / 删除），或导出世界书 JSON / 复制世界书条目 JSON（网页版没有酒馆接口，写入世界书请用扩展版）。存档存在本浏览器 localStorage。

## 省 API

- 默认开「省流」：七遍读合并成一次调用返回，少花一半调用；取消勾选可分步细读。
- 参考草稿并入读解一次返回，切「来源」不会因此重跑整段分析。
- 每个步骤按输入算指纹做缓存，每阶段保留最近 5 次结果，重复点不重复请求。
- 一次调用没结束时，重复点按钮会被忽略，不会并发重复发请求。
- 前三遍读的每一层可单独「重蒸」，不必整段重读。
- 压成块用读解剪出的样本，不再重发整篇语料。
- 顶部显示已调用次数、省下的次数与 token。

## 文件

- `index.html` 结构（悬浮球 + 悬浮面板）
- `style.css` 样式
- `prompts.js` 六遍读 / 按层重蒸 / 成块 / 改写的提示词
- `app.js` 状态、API 调用、缓存、悬浮窗、步骤流转

## 设计来源

方法取自两个公开的蒸馏 skill 的纪律：两个人工卡点、黑名单至少 6 条且由用户补最锋利的一条、借结构不借句子、用默认 AI 腔文字做测试门。

## 边界

- 只蒸馏自己的或已获授权的语料。
- 语料默认不出域，只发给用户自己配置的 API。
- 未来会作为 SillyTavern 第三方扩展接入，当前只做静态版。
