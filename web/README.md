# 大厨烹饪处（静态版）

纯前端静态页面。语料进，文风块出。文风块是一段纯文字，可以被填进 SillyTavern 预设的一条 prompt，或世界书的一条 entry；本工具不生成容器，也不碰 keys / position / order。

## 用法

1. 打开页面，点右上角「API 设置」，填入 OpenAI 兼容接口的 Base URL、Key、模型。Key 只存在当前浏览器的 localStorage。
2. 「喂料」：选来源与体裁，贴同一体裁的语料，起个名字。
3. 「开始六遍读」。
4. 「卡点·信念」：选 / 驳 / 修 AI 给的信念候选，确认后读后三遍。
5. 「卡点·反例」：AI 列黑名单，你补那条最锋利的反例。
6. 「压成文风块」。
7. 「测试门」：拿一段默认 AI 腔让它用文风改写，你判像不像；不像就回去只重蒸漂的那层。
8. 「拿走」：复制文风块，或下载 JSON / 蒸馏池。

## 文件

- `index.html` 结构
- `style.css` 样式
- `prompts.js` 六遍读 / 成块 / 改写的提示词
- `app.js` 状态、API 调用、步骤流转

## 设计来源

方法取自两个公开的蒸馏 skill 的纪律：两个人工卡点、黑名单至少 6 条且由用户补最锋利的一条、借结构不借句子、用默认 AI 腔文字做测试门。

## 边界

- 只蒸馏自己的或已获授权的语料。
- 语料默认不出域，只发给用户自己配置的 API。
- 未来会作为 SillyTavern 第三方扩展接入，当前只做静态版。
